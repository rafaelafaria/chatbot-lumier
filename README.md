# 🎬 ChatBot LUMIER

Assistente virtual para cinema, desenvolvido como projeto acadêmico do curso de Ciência da Computação na Universidade São Judas Tadeu.

## Sobre o projeto

O LUMIER é um chatbot que ajuda o usuário a escolher o que assistir e encontrar cinemas em São Paulo. Ele foi desenvolvido utilizando o Dialogflow e está integrado à plataforma Telegram.

## Funcionalidades

- 🎥 Recomendação de filmes por gênero e humor
- 📍 Consulta de cinemas e programação em São Paulo
- 🎬 Filmes em cartaz atualmente

## Tecnologias utilizadas

- Dialogflow (processamento de linguagem natural)
- Telegram (integração e interface do bot)
